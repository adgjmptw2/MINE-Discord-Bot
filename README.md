## 기능

- **노래 채널(Soundroom)**: `/세팅`으로 전용 텍스트 채널과 패널을 만든 뒤, 채팅 검색어·패널 버튼·대기열·플레이어 버튼으로 재생·대기열·일시정지 등을 조작합니다. (`/play`·24/7 등 일반 음악봇용 슬래시 루트는 넣지 않았습니다.)
- **플레이리스트**: `/playlist` (`/플레이리스트`) — `create` / `add` / `load` / `view` / `remove` / `delete`
- **인기차트**: 전역 유튜브 재생목록. `.env`의 `DISCORD_OWNER_IDS` 제작자만 `/melon_chart` (`/인기차트-관리`)로 등록·해제
- **SQLite 저장소**: 서버 설정, 최근 재생, 플레이리스트 등. DB는 레포 **`/storage/`**, `*.sqlite`는 `.gitignore`
- **주식 모의투자 게임**: 서버별 가상 화폐로 주식을 사고팔 수 있는 슬래시 명령. 아래 [주식 모의투자 게임](#주식-모의투자-게임)과 [docs/stock-investing.md](docs/stock-investing.md) 참고

## 주식 모의투자 게임

### 기능 개요

서버별 가상 화폐 **코인**으로 국내 인기 주식 5개를 사고파는 **모의투자 게임**입니다. 실제 돈, 현물 보상, 환전 기능은 없으며 **실제 투자 판단에 사용할 수 없습니다.** 시세·평가는 **지연되거나 부정확할 수 있습니다.** 가격 소스는 **`StockQuoteProvider`** 구현을 바꿔 `mock` / `yahoo` / `twelvedata` 등으로 교체할 수 있게 나누어 두었습니다.

### 슬래시 명령어

| 명령어      | 설명                                    |
| ----------- | --------------------------------------- |
| `/출석`     | 하루 1회 가상 화폐를 받습니다           |
| `/자산`     | 내 현금, 보유 주식, 총자산을 확인합니다 |
| `/주식목록` | 지원 종목과 시세 상태를 확인합니다      |
| `/시세`     | 특정 종목의 모의투자 시세를 확인합니다  |
| `/매수`     | 가상 화폐로 주식을 매수합니다           |
| `/매도`     | 보유 주식을 매도합니다                  |
| `/주식랭킹` | 서버별 총자산 랭킹을 확인합니다         |

### 환경 변수

| 변수                             | 설명                                                                                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `STOCK_PRICE_PROVIDER`           | `mock`: 개발용 가짜 가격 · `yahoo`: 국내주 MVP용 demo/delayed (공식 API 아님) · `twelvedata`: Twelve Data API                                                                |
| `STOCK_PRICE_REFRESH_INTERVAL_MS` | 기본 **300000** ms (5분). 너무 낮은 값은 설정에서 **최소 60000** ms 등으로 보정될 수 있음                                                                                    |
| `TWELVE_DATA_API_KEY`            | `twelvedata` 사용 시 필요. `mock` / `yahoo`만 쓸 때는 불필요                                                                                                               |

### 개발·테스트 순서

1. `.env`에서 `STOCK_PRICE_PROVIDER=mock` 설정
2. `npm run check`
3. `npm run build`
4. `npm run start:bot`
5. Discord **일반 텍스트 채널**에서 `/출석`
6. `/주식목록`
7. `/시세` 종목: `삼성전자`
8. `/매수` 종목: `삼성전자` 금액: `5000`
9. `/자산`
10. `/매도` 종목: `삼성전자` 매도: `50%`
11. `/주식랭킹`

국내주 MVP는 `yahoo` 또는 `mock`으로도 같은 순서로 확인할 수 있습니다.

### Provider·시세 구조

- 슬래시 명령은 **외부 시세 API를 직접 호출하지 않습니다.**
- **`StockMarketService`**가 일정 주기로 가격을 가져와 **메모리에 캐시**합니다.
- `/시세`, `/매수`, `/매도`, `/주식랭킹`, `/자산` 등은 이 **캐시된 가격**을 기준으로 동작합니다.
- **API 호출량을 줄이고**, Provider 구현만 바꿔 **데이터 소스 교체**를 쉽게 했습니다.
- **Yahoo provider**는 공식 투자용 API가 아니라 **demo/delayed quote** 수준입니다. 운영·공개 환경에서는 정식 라이선스 Provider로 바꾸는 것을 권장합니다.

### 알려진 한계

- 현재는 **시장 운영 시간 제한 없음**
- **시즌제 없음**
- **예약·지정가 주문 없음**
- **Yahoo provider**는 공식 투자용 데이터가 아님
- 가격 데이터는 **지연되거나 누락**될 수 있음
- 대규모 서버에서는 **랭킹 집계 최적화**가 필요할 수 있음
- 본 기능은 **모의 게임**이며 실제 투자용이 아님

### 포트폴리오 관점

Discord **slash command** 기반 인터랙션, SQLite **서버별 지갑·보유·거래**, **Provider 인터페이스**로 시세 소스 분리, **캐시 기반** 조회, 트랜잭션 **매수·매도**, **서버별 랭킹** 계산.

## 준비

1. Node.js 20 이상을 설치합니다.
2. Lavalink 서버를 준비합니다.
3. `.env.example`을 복사해서 `.env`를 만들고 값을 채웁니다.

```bash
npm install
npm run start:bot
```

`start:bot`과 `start`는 실행 전에 자동으로 `build`를 돌립니다. `dist`만 갱신하려면 `npm run build`만 실행하면 됩니다.

**패키지 매니저:** 기본은 **npm**(`package-lock.json`)입니다. Bun으로도 실행할 수 있어 **`bun.lock`**도 함께 두었습니다.

Bun 예시:

```bash
bun install
bun run start:bot:bun
```

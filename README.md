## 기능

- **노래 채널(Soundroom)**: `/세팅`으로 전용 텍스트 채널과 패널을 만든 뒤, **채팅 검색어·패널 버튼·대기열 패널·(일반 채널의) 플레이어 버튼**으로 재생·대기열·일시정지 등을 조작합니다. 레포에는 `/play`·24/7·가사·Top.gg 투표 같은 **일반 음악봇용 슬래시 루트는 넣지 않았습니다.**
- 플레이리스트: **`/playlist`**(한국어 표기: **`/플레이리스트`**) 한 개만 등록합니다. 서브커맨드는 `create` / `add` / `load` / `view` / `remove` / `delete`입니다.
- 인기차트: **전역** 유튜브 재생목록 하나입니다. `.env`의 `DISCORD_OWNER_IDS`에 넣은 **제작자만** `/melon_chart`(또는 `/인기차트-관리`)로 등록·해제할 수 있습니다. 등록해 두면 **모든 서버**의 노래 채널 **[인기차트]** 버튼이 같은 목록을 재생합니다.
- SQLite 저장소: 서버 설정, 최근 재생, 플레이리스트를 저장합니다. 런타임 DB는 레포 루트 **`/storage/`**에 두고, `*.sqlite`는 `.gitignore`에 포함했습니다. 저장소 파일을 커밋했다면 `git rm --cached -r --ignore-unmatch storage/*.sqlite`로 한 번 정리한 뒤 다시 커밋하면 됩니다.
- **주식 모의투자 게임**: 서버별 가상 화폐로 주식을 사고팔 수 있는 슬래시 명령 모음입니다. 아래 [주식 모의투자 게임](#주식-모의투자-게임)과 [docs/stock-investing.md](docs/stock-investing.md)를 참고하세요.

## 주식 모의투자 게임

서버별 가상 화폐 **MINE**으로 국내 인기 주식 5개를 사고파는 **모의투자 게임**입니다. 실제 돈, 현물 보상, 환전 기능은 없으며 **실제 투자 판단에 사용할 수 없습니다.** 시세는 지연되거나 부정확할 수 있습니다. 가격 데이터 소스는 **`StockQuoteProvider` 구현을 바꾸는 방식**으로 교체할 수 있게 나누어 두었습니다.

### 환경 변수 (주식)

| 변수 | 설명 |
|------|------|
| `STOCK_PRICE_PROVIDER` | `mock`: 개발용 가짜 가격 · `yahoo`: 국내주 MVP 검증용 demo/delayed quote provider · `twelvedata`: Twelve Data API provider |
| `STOCK_PRICE_REFRESH_INTERVAL_MS` | 시세 갱신 주기. 기본 **300000**ms(5분). 설정값이 너무 짧으면 **최소 60000**ms로 보정됩니다. |
| `TWELVE_DATA_API_KEY` | `twelvedata` 사용 시 필요. `mock` / `yahoo`만 쓸 때는 불필요합니다. |

### 개발·테스트 순서 (추천)

1. `.env`에서 `STOCK_PRICE_PROVIDER=mock` 설정
2. `npm run check`
3. `npm run build`
4. `npm run start:bot`
5. Discord **일반 텍스트 채널**에서 `/출석`
6. `/주식목록`
7. `/시세` 종목: `삼성전자`
8. `/매수` 종목: `삼성전자` 금액: `5000`
9. `/자산`
10. `/매도` 종목: `삼성전자` 매도: `50%`
11. `/주식랭킹`

국내주 MVP는 `yahoo` demo/delayed provider 또는 `mock`으로도 같은 순서로 테스트할 수 있습니다.

### Provider·시세 구조 (주의)

- **Yahoo provider**는 공식 투자용 데이터가 아닙니다. 공개·운영 환경에서는 **정식 라이선스가 있는 데이터 Provider**로 바꾸는 것을 권장합니다.
- 슬래시 명령은 외부 시세 API를 직접 부르지 않고, **`StockMarketService`가 주기적으로 채운 캐시**만 읽습니다. 덕분에 호출량을 줄이고 Provider 교체 시 명령 코드 변경을 최소화할 수 있습니다.

### 알려진 한계

- 장 운영 시간 제한 없음 · 시즌제 없음 · 예약/지정가 주문 없음
- 시세는 지연·데모 Provider일 수 있음
- 대규모 서버에서는 랭킹 집계 최적화가 필요할 수 있음
- 본 기능은 모의 게임이며 실제 투자용이 아님 ★

### 포트폴리오 관점 (한 줄 요약)

Discord 인터랙션 기반 게임 플로우, SQLite 지갑·보유·거래, **Provider 인터페이스로 시세 소스 분리**, **캐시 기반 조회**로 API 부담 완화, 트랜잭션 기반 매수·매도.

더 자세한 설명·데이터 모델·시나리오는 **[docs/stock-investing.md](docs/stock-investing.md)** 를 참고하세요.

## 준비

1. Node.js 20 이상을 설치합니다.
2. Lavalink 서버를 준비합니다.
3. `.env.example`을 복사해서 `.env`를 만들고 값을 채웁니다.

```bash
npm install
npm run start:bot
```

`start:bot`과 `start`는 실행 전에 자동으로 `build`를 돌립니다. `dist`만 갱신하려면 `npm run build`만 실행하면 됩니다.

**패키지 매니저:** 기본은 **npm**(`package-lock.json`)입니다. Bun으로도 실행할 수 있어 **`bun.lock`**도 함께 두었습니다. 둘 중 하나만 사용해도 되고, 둘 다 맞추려면 `npm install`과 `bun install`을 각각 실행하면 됩니다.

Bun 예시:

```bash
bun install
bun run start:bot:bun
```

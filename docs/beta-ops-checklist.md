# 베타 운영 체크리스트

배포·VM 준비·`.env`·Lavalink는 [배포 가이드](./deployment.md)를 먼저 보세요.

배포·베타 운영 전후에 순서대로 확인합니다.

## 실행 전

- [ ] `.env` 설정 확인
- [ ] Lavalink 실행 확인
- [ ] Lavalink를 `-Xms512m -Xmx1536m` 옵션으로 실행 ([배포 가이드](./deployment.md) Lavalink JVM 메모리 섹션 참고)
- [ ] `/상태`에서 음악·Lavalink 연결 상태 확인
- [ ] 장시간 재생 중 **java**(Lavalink) 프로세스 메모리 사용량 확인
- [ ] `npm run check` 성공
- [ ] `npm run build` 성공
- [ ] `npm run start:bot` 성공 (로컬 Lavalink 한 터미널이면 `LAVALINK_JAR_DIR` 설정 후 `npm run start:all` 로 대체 가능)

## 운영 메모

- VM·`.env`·Lavalink 요약은 [배포 가이드](./deployment.md) 참고

- Yahoo provider는 demo/delayed 성격

- 실제 돈·환전·현물 보상 없음

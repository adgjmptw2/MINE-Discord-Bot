# 개인정보 안내 (초안)

이 문서는 MINE Discord 봇의 **운세 프로필(저장형 `/오늘운세`)** 과 관련해, 어떤 정보가 어떻게 다루어지는지를 설명하기 위한 안내입니다. 법률 자문이나 공식적인 개인정보처리방침을 대체하지 않습니다.

## 1. 수집·저장하는 항목

- **Discord 사용자 ID** (`user_id`): 누구의 프로필인지 구분하기 위해 사용합니다.
- **암호화된 운세 프로필** (SQLite `fortune_profiles` 테이블의 `profile_ciphertext`, `profile_iv`, `profile_tag` 등): 평문으로 저장하지 않습니다.
- **프로필을 복호화했을 때의 내부 데이터**(서버 메모리 상에서만): 생년월일(`YYYY-MM-DD`), 성별(`male` / `female` / `other` / `private`).
- **메타데이터**: 동의·안내 버전(`privacy_notice_version`), 동의 시각(`consented_at`), 생성·수정 시각(`created_at`, `updated_at`) 등.

일회용 운세는 생년월일·성별을 **DB에 저장하지 않습니다.**

## 2. 수집 목적

- `/오늘운세` **저장형** 기능: 사용자가 다음에 같은 명령으로 다시 입력하지 않아도 오늘의 재미용 운세를 보여 주기 위함입니다.

## 3. 보관 기간

- 사용자가 봇에서 **삭제하기**를 실행하거나, DB 행이 삭제될 때까지 저장될 수 있습니다.
- 봇 운영자가 서버·DB를 정리하거나 봇 서비스를 종료하는 경우, 데이터가 더 이상 보관되지 않을 수 있습니다.

## 4. 삭제 방법

- 서버 채널에서 `/오늘운세` 실행 후, 저장된 프로필이 있을 때 표시되는 **삭제하기** 버튼으로 삭제할 수 있습니다.
- 기술적 문제로 삭제가 어려운 경우: **[디스코드 mine2188]** 로 문의해 주세요. (README·봇 프로필 등에 안내된 연락처로 대체하시면 됩니다.)

## 5. 제3자 제공

- 운세 프로필 데이터를 제3자에게 판매·임대하거나, 별도 계약 없이 제공하지 않습니다.

## 6. 외부 API 전송

- 운세 계산을 위해 생년월일·성별을 **외부 API로 전송하지 않습니다.** (재미용 문구는 봇 내부에서만 생성합니다.)

## 7. 암호화

- 저장형 프로필 JSON은 **AES-256-GCM**으로 암호화한 뒤 DB에 저장합니다.
- 암호화에 쓰는 키는 **`.env`의 `FORTUNE_PROFILE_ENCRYPTION_KEY_BASE64`** 에서만 읽으며, DB나 코드에 넣지 않습니다.
- 키는 **32바이트(256비트)** 를 Base64로 인코딩한 값이어야 합니다. 예시 생성:

  ```bash
  node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
  ```

## 8. 운세 관련 주의

- 운세는 **재미용**이며, 실제 의사결정·투자·건강·법률·재정 판단에 사용하지 마세요.

## 9. 코인·주식 안내

- MINE의 코인·주식 기능은 **서버 내 가상 기능**이며, 실제 돈·환전·현물 보상과 관련되지 않습니다.

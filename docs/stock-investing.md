# 주식 모의투자 게임

## 개요

서버(길드)마다 **가상 화폐 코인**과 **지갑·보유·거래 기록**을 두고, 국내 대형주 5종을 사고팔 수 있는 **모의투자용 미니 게임**입니다. 실제 돈, 현물 보상, 환전은 없고, **실제 투자 판단·세무·법적 판단에 쓰면 안 됩니다.** 시세는 **지연되거나 부정확할 수 있습니다.**

## 데이터 모델 (요약)

- SQLite `stock_wallets`: 길드별·유저별 현금, 누적 입금(수익률 기준)
- `stock_holdings`: 심볼별 보유 수량(마이크로 단위, 1주 = 1,000,000), 평균 매수가
- `stock_trades`: 매수·매도 세부(BUY·SELL, 수수료, 실현손익 등)
- `stock_daily_attendance`: 출석 일자별 보상 기록

명령 처리와 시세 조회는 Drizzle 없이 **raw SQL + 트랜잭션**으로 처리합니다.

## Provider 구조

가격은 **`StockQuoteProvider`** 구현체가 주기적으로 가져오고, **`StockMarketService`**가 메모리에 캐시합니다. 슬래시 명령은 **외부 API를 직접 호출하지 않고** `client.stockMarket`의 캐시만 읽습니다. 이렇게 해서:

- API 호출 횟수를 일정 주기로 묶을 수 있고
- Provider만 바꿔도 데이터 소스를 교체할 수 있습니다.

지원 Provider 종류(환경 변수 `STOCK_PRICE_PROVIDER`):

| 값 | 설명 |
|---|---|
| `mock` | 개발용 가짜 시세 |
| `yahoo` | 국내주 MVP 검증용 **demo/delayed** 시세 (비공식, 투자용 아님) |
| `twelvedata` | Twelve Data API (키 필요) |

## 테스트 시나리오

로컬에서 아래 순서로 동작을 확인할 수 있습니다.

1. `.env`에서 `STOCK_PRICE_PROVIDER=mock` (또는 `yahoo`)
2. `npm run check` → `npm run build` → `npm run start:bot`
3. Discord **일반 텍스트 채널**에서 (Soundroom 전용 채널은 정책상 일부 슬래시가 제한될 수 있음):
   - `/출석` → `/주식목록` → `/시세 종목:삼성전자`
   - `/매수 종목:삼성전자 금액:5000` → `/자산`
   - `/매도 종목:삼성전자 매도:50%` → `/주식랭킹`

## 알려진 한계

- 장 운영 시간·휴장일 등 **거래 시간 제한 없음** (개발·야간 테스트 용이)
- 시즌제, 예약·지정가 주문 없음
- 시세는 demo/delayed 또는 mock일 수 있음 → **정확한 시세를 보장하지 않음**
- `/주식랭킹`은 길드 전체 지갑을 읽어 메모리에서 집계하는 MVP 방식 → **대규모 서버에서는 최적화가 필요할 수 있음**
- 본 기능은 **모의 게임**이며 실제 투자 도구가 아님

## 포트폴리오 관점 (구현 요약)

- Discord **슬래시 인터랙션** 기반 게임 플로우
- SQLite로 **서버별 지갑·보유·거래** 영속화
- **Provider 인터페이스**로 시세 소스 분리, **캐시**로 조회 경로 단순화 및 호출 절감
- 매수·매도는 **트랜잭션**으로 잔고·보유 일관성 유지

# 주식 모의투자 — 수동 테스트 체크리스트

Discord 일반 텍스트 채널에서 테스트합니다.

Soundroom 전용 채널은 서버 설정에 따라 일부 슬래시가 제한될 수 있습니다.

발견한 버그는 코드 수정 전 Known issues에만 적어 둡니다.

슬래시 명령은 클라이언트 입력 그대로 기록합니다.

재현이 어려운 경우 환경 변수와 봇 로그 시점을 함께 적습니다.

## 테스트 환경

- [ ] Node.js 20+
- [ ] .env 설정 완료
- [ ] npm run build 성공
- [ ] npm run start:bot 성공

## Mock provider 테스트

- [ ] STOCK_PRICE_PROVIDER=mock 설정
- [ ] /주식목록에 mock 시세 표시
- [ ] /시세 종목:삼성전자 응답 확인

## 시세·종목 입력

- [ ] `/시세`에 지원 종목 입력 시 시세 표시
- [ ] `/시세`에 미지원 종목·오타 입력 시 지원 목록 안내

## Yahoo provider 테스트

- [ ] STOCK_PRICE_PROVIDER=yahoo 설정
- [ ] /주식목록에 가격 표시
- [ ] 실패 시 Known issues에 기록

## 출석 테스트

- [ ] /출석 최초 실행 시 10,000 MINE 지급
- [ ] 같은 날 /출석 재실행 시 중복 지급 없음

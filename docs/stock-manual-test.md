# 주식 모의투자 — 수동 테스트 체크리스트

Discord **일반 텍스트 채널**에서 테스트합니다. Soundroom 전용 채널은 서버 설정에 따라 일부 슬래시가 제한될 수 있습니다.

발견한 버그는 코드 수정 전 **[Known issues](#known-issues)** 에만 적어 두고, 추후 단계에서 처리합니다.

## 테스트 환경

- [ ] Node.js 20 이상
- [ ] `.env`에 `TOKEN`, `CLIENT_ID` 등 봇 실행에 필요한 값 설정
- [ ] `npm run build` 후 `npm run start:bot`으로 기동

## Mock provider 테스트

- [ ] `.env`에서 `STOCK_PRICE_PROVIDER=mock`
- [ ] 봇 기동 후 시세 캐시가 채워지는지 확인 (`/주식목록` 등)

## Yahoo provider 테스트

- [ ] `.env`에서 `STOCK_PRICE_PROVIDER=yahoo`
- [ ] 시세 갱신 후 `/주식목록`, `/시세`에 가격이 표시되는지 확인 (네트워크·레이트 제한 시 실패 가능 → Known issues에 기록)

## 출석 테스트

- [ ] `/출석` 최초 실행 시 **10,000 코인** 지급 안내
- [ ] 같은 날 `/출석` 재실행 시 **중복 지급 없음** 안내

## 매수 테스트

### 성공

- [ ] `/매수` 종목 `삼성전자` 금액 `5000` 실행 후 체결 안내
- [ ] `/자산`에 보유 종목·현금 변화 반영

### 실패

- [ ] 지갑 없음: `/출석` 없이 `/매수` 시 안내 문구
- [ ] 잔액 부족: 보유 현금보다 큰 금액으로 `/매수`
- [ ] 미지원 종목: 존재하지 않는 종목명으로 `/매수`
- [ ] 시세 캐시 없음: 시세 미준비 상태에서 매수 시 안내 (재현 방법은 환경에 따라 Known issues 참고)

## 매도 테스트

### 성공

- [ ] `/매도` 종목 `삼성전자` 매도 `50%` 후 보유 수량 감소·현금 증가
- [ ] `/매도` 종목 `삼성전자` 매도 `전부` 후 해당 종목 보유 없음
- [ ] `/매도` 종목 `삼성전자` 매도 `3000`(금액) 등 금액 방식 동작

### 실패

- [ ] 보유 없음: 해당 종목 미보유 시 안내
- [ ] 보유 부족: 금액 매도 시 보유를 초과하는 금액
- [ ] 잘못된 퍼센트: `0%`, `101%`, 소수 퍼센트 등
